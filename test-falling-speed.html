Device-Independent Falling Speed Bugfix

⚠️ CRITICAL: This test is designed to FAIL on unfixed code. Test failure confirms the bug exists and demonstrates the frame rate dependency issue.

Test Overview

Property 1: Fault Condition - Inconsistent Falling Speed Across Frame Rates

Validates Requirements: 1.1, 1.2, 1.3, 1.4

Bug Condition: The game uses fixed delta time (1/60) regardless of actual frame rate, causing physics to accumulate at the device's frame rate frequency instead of real time.

Test Strategy:

  • Simulate different frame rates by controlling requestAnimationFrame timing
  • Measure cat's Y position over a fixed real-world time period (2 seconds)
  • Test falling distance at: 45, 60, 90, 120, 144 FPS
  • Compare falling distances - expect significant differences on unfixed code
